## 3. 서초점과의 연결
- 서초점 영상: "3M PWF, 프리미엄 컬러PPF를 선택하는 이유ㅣ3M프로이즘 강남서초점"(11개월 전, 5:51, 1,438회). 설명란에 "서초점 진준호 대표님", 필름은 **사틴블랙 PWF**. 채널 최근 1년 안에서 상위권 조회수
- 블로그에서 반복되는 주제(크롬죽이기·컬러PPF·신차패키지)가 유튜브에서도 조회가 나오는 주제와 같다. 즉 영상 주제를 새로 찾을 필요가 없고, 블로그 글 하나를 영상 하나와 짝짓는 구조가 맞다
- 노션 "영상 진행 참고"(PD 촬영 가이드: 오프닝 15~20초 → 시공점·본인 소개 → 작업 특징 → 엔딩, 5분 내외, 인서트컷+음성 위주)가 채널의 최근 포맷

## 4. 로컬 시스템에 붙일 수 있는 것 (아직 안 함)
1. **블로그 ↔ 영상 짝 연결**: 시공기 발행 때 같은 차의 유튜브 영상이 있으면 글 끝 영상 자리에 유튜브 링크 카드도 추천. 발행 글 DB(blog_posts)에 youtube_id 칸 하나면 됨. 반대로 영상 설명란에 블로그 글 링크 + 서명 문구를 자동 생성
2. **영상 설명란·제목 생성기**: 블로그 본문 사실만으로 유튜브 제목 후보 3개(채널의 잘 된 제목 꼴: "~의 모든 것", "~하는 이유", "N년 뒤 뜯었더니")와 설명란(요약 + 서명 + 지도 + 블로그 링크 + 해시태그)을 만든다. 지금 인스타·카페 버전 만드는 channels.ts 에 'youtube' 채널 하나 추가하는 일
3. **자막 → 사장님 말투 학습**: 사장님이 말하는 영상의 자막을 받아 두면 문자·문의 답변 말투 학습에 쓸 수 있다. 이번엔 브라우저로 자막을 못 가져왔고(자동 생성 자막 요청이 빈 응답), 방법은 둘: 유튜브 스튜디오에서 자막 파일 내려받기(사장님 계정) 또는 이미 있는 말하기 영상 파이프라인(whisper)으로 영상 파일을 직접 받아쓰기
4. **주간 집계에 유튜브 줄 추가**: 미팅 기록에 "롱폼 N건·숏폼 N건"을 손으로 적고 있음. 채널 페이지를 주 1회 읽어 이번 주 업로드 수와 최근 영상 조회수를 월요일 브리핑에 넣을 수 있다(로그인 없이 읽힘)
5. **숏폼 공백**: 채널에 숏폼이 사실상 없고, 노션 아이디어에 릴스 안이 많다. 우리 영상 파이프라인의 세로 몽타주(이번 CLE 40초처럼)가 그대로 쇼츠 재료가 된다. 인스타 영상은 중단했지만 유튜브 쇼츠로 올릴지는 별개 결정

## 5. 결정이 필요한 것
- 서초점 영상을 이 채널에 계속 올릴지, 서초점 채널을 따로 둘지(블로그·플레이스는 서초 따로, 유튜브는 통합인 상태)
- 자막을 어떤 경로로 받을지(스튜디오 내려받기 vs whisper)
- 4번 주간 집계를 마케팅팀 브리핑에 넣을지
