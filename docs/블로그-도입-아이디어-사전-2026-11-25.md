## 본문 흐름 유형

1. **부위 순서형**(roice_·effort 다수): 전처리 한 문단 → 범퍼·본넷·휀다·도어… 부위마다 짧은 소제목 줄 + 어디까지 넣었는지 → 결과 → 서명. 가장 흔함.
2. **손님 심리형**(poi): 손님이 왜 바꾸고 싶었나 두세 문단 → 색·제품 고른 이유 → 작업은 짧게 → 결과물 중심.
3. **정보 글형**(effort·poi): 질문/오해 → 원리·기준 → 우리 매장 사례 한 건 → 손님은 어떻게 하면 되는지. FAQ 모드와 같은 뼈대.
4. **재방문형**(poi): 전 작업 상태 확인(들뜸 없음 등) → 이번 작업 → 관리 안내.
5. **매장 일지형**(poi "작업칸이 재방문 고객으로 만석", effort "오전부터 비가 오네요"): 매장 근황 한두 줄 → 오늘 차.

## 마무리

셋 다 고정 서명: (감사 한 줄) → "궁금할 땐 네이버 톡톡하세요!" → 상호 → 주소. roice_ 206/216편. 변주는 감사 문장 한 줄만("긴 글 읽어주셔서 감사합니다" / "필요한 시공이 있다면 언제든"). 핵심 규칙 ⑤ 그대로.

## 쓰지 않는 것(세 블로그에 많지만 우리 규칙과 충돌)
