# 사장님 구글 드라이브 시트·문서 정리 (2026-11-18)

사장님이 "사진 폴더가 아니라 시트·문서가 중요하다"며 드라이브 홈을 보여 줌. 브라우저 창(사장님 구글 로그인)으로 읽기만 했고 아무것도 고치지 않음.

## 2. 바로 보이는 연결
1. **유입경로 월별 표 자동화** — CRM customers.유입경로(같은 7항목)와 상담 기록 날짜로 같은 표(일×경로, 합계·비율)를 월요일 브리핑과 홈에 만든다. 손으로 1씩 적던 일이 없어지고, 실장님께 공유할 때는 표만 복사. 주간 집계(2번)의 첫 줄로 넣기 좋음
2. **유입경로 추세** — 8월 28건(소개/재방문 12) → 9월 17 → 10월 17 → 11월 2(진행 중). 소개/재방문 비중이 8월엔 43%, 10월엔 18%. 후기 추적(3번)과 재방문 글 형식이 왜 필요한지 숫자로 보임
3. 2023 상담 차트 11건은 고객 엑셀 일괄 등록 때 같이 넣을지 결정
4. 카페 댓글 응대 멘트는 문의 답변 기능에 "카페 댓글용" 짧은 형식으로 붙일 수 있음(쪽지로 보냈다 + 연락처 한 줄)

## 3. 사장님 확인 필요
- 스펙관리 시트는 무엇을 넣으려던 것인지
- 매장운영관리대장·시공내역서 엑셀의 용도(CRM이 대체했는지)
- 시트에 평문으로 있는 계정·비밀번호는 옮기거나 지우는 것이 안전
