## 지운 문단 (초안에 있었으나 발행에서 뺌)
1. 초밥 비유 전체(10만 원·1만 원·1천 원 초밥) → "세상에는 불변의 법칙 / 싸고 좋은 물건은 없다는 말이 있습니다 / 값이 싼 제품은 그만한 이유가 있는것이죠" 세 줄로 교체. 사장님 공지 글에 있던 비유인데도 이 글에서는 뺌
2. "제 입장부터 말씀드리면 … 시공하는 사람 손 얘기가 먼저 나올 줄 아셨을 텐데" 문단
3. "들뜸이 올라오는 자리는 패널 끝, 접히는 데, 엠블럼과 손잡이 주변부터" 한 문장
4. **포스트잇 문단 전체**(수직으로 떼기 힘듦, 미세 구체) — 어제 "담백하게 넣어 달라"고 하셨던 것인데 발행에서는 뺌. "순간접착제 폼테이프 포스트잇처럼"은 남김
5. "영구 부착용이지만", "다만 이건 제조사 설명이고 차 상태는 차마다 다르니 저는 따로 확인하고 들어갑니다", "프로이즘이 3M을 택하고 협력하고 있는 것도 이런 이유" — 단서 문장 삭제(입장을 흐리는 단서는 뺀다, FAQ 교훈과 같음)
6. 교육 문단("솔직히 교육을 받기 전에는 … 5년 뒤에 나요")과 3M 마크·트레이닝 센터 문단 → 아래 '라면' 문단으로 교체
7. "저희도 지금 소개와 재방문이 주된 예약입니다", 상담 문단, 전화 줄, 서명, 해시태그

## 더한 문단 (사장님이 직접 씀)
1. PPF 정의: "Paint Protection Film의 약자", "군용으로 군용장비를 보호", "TPU 성질의 필름", "역사와 함께 사전적 정의부터" — 사전적 정의를 짧게 넣는 것을 좋아함
2. "저는 매장에서 PPF시공을 매일같이 하며 … 필름을 여러 번 제거해봤습니다" — '하자를 봤다' → '제거해 봤다'로 경험을 구체화
3. **"이러한 필름을 잘 다루기 위해서는 개인의 역량 또한 중요 / 아무리 좋은 식재료를 갖다 놓는다해도 식재료를 다루는 능력이 없다면 라면보다 못한 요리가 될 수 있습니다"** + **"저는 3M에서 인증하는 프리퍼드 인스톨러 교육을 수료한 글로벌 브랜드 3M이 인정한 기술자입니다 / 항상 매 작업기에서 포스트 히팅 후 열처리를 꼼꼼하게 하고 있고 / 너무 강한 열이 아닌 적재적소에 알맞은 기술로 모서리 마감까지도 높은 퀄리티로"**
   - 사장님이 PPF 글에 **포스트 히팅·열처리**를 직접 썼다. 지금 규칙(PPF 열 표현 금지, checkHardViolations)과 충돌 → 사장님께 확인: 3M SOP 의 포스트 히팅은 써도 되는지
   - "3M이 인정한 기술자" 선언형 자기소개도 직접 씀 — 작업자 강조 금지 규칙의 범위를 다시 물을 것
4. 마무리: "3M PPF는 그냥 3M이라서 좋은게 아닙니다 / 글로벌 브랜드만의 기술력 … 수명이 다해 제거할때까지도 고려해서 만든 안전한 PPF" + "최근에는 저가형 PPF가 정말 시중에 많이 유통 … 가격때문에 차량 도장면을 손상시키는 시공을 선택하진 마시길" + "소중한 차량에는 소중한 필름으로 시공하세요"
5. **"3M 뿐 아니라 다른 필름도 취급하고 있으니 언제든 문의전화, 문자 부탁드립니다 / 성심껏 응대드리겠습니다"** — 새 사업 사실: 다른 필름도 취급. 지금까지 글·문자는 3M 만 쓰는 전제였음 → 사장님께 확인 뒤 BUSINESS_CONTEXT 반영

## 남긴 것 (초안 그대로 또는 거의 그대로)
- 썬팅은 차이를 아는데 PPF는 모른다는 도입(유튜브에서 가져온 틀)
- 저가 쿠폰 필름·원산지 모를 원단·보증서 없음 사례, "외장을 위해 한 시공이 외장에 손상", "시공비가 저렴한 가장 큰 이유는 필름 값", "양산형 시공을 하는 곳이 아닙니다"
- 5년 이상 붙이는 물건 → 좋은 필름의 두 조건 → 점착제 이야기로 넘어가는 다리
- 접착력만 센 필름 / 자리 못 잡는 필름 두 방향 설명 거의 전문
- 3M 접착제 회사 설명(순간접착제·폼테이프·포스트잇, 건물 패널~아이 피부), 감압형 점착제 설명, 공인 시공점 제거 안내
- "당장 판단하지 않으셔도 됩니다 / 필름의 진가는 시간이 지나면서 표면 위로 드러납니다"
